# 意見反應表單改由 Apps Script 寄信（GitHub Pages 沒有表單後端）

原本的表單靠 Netlify Forms 收件：POST 到 `public/forms/contact.html`，Netlify 在建置時偵測該檔的隱藏表單。網站改部署到 GitHub Pages 之後，那個路徑只是一個靜態檔，POST 會失敗，表單等於壞掉。

## 決定

**沿用既有的 Apps Script 網頁應用程式**，新增一個不需登入的 `contact` 動作，收到後用 `MailApp` 寄信給公司信箱。

- **不新增第三方服務**（Formspree 之類）：那要再開一個帳號、再管一組額度與隱私條款；Apps Script 已經部署好、已經授權、而且網址與後台共用一個。
- **只寄信，不寫試算表**。內容試算表是「發布到網路」的，把來信者的姓名、電話、E-mail 寫進去等於對外公開。要留存底的話 Gmail 本身就是紀錄；真的需要時再開一份**不發布**的獨立試算表。
- **收件方式用環境變數切換**（`VITE_CONTACT_API_URL`），Netlify Forms 的程式與測試都保留。這樣兩種主機都還能用，也不會因為換主機又改一次程式。
- **防濫用**：蜜罐欄位（填了就回成功但不寄）、欄位長度上限、以 `CacheService` 做全站每 10 分鐘 10 封的上限。沒有圖形驗證碼——舊站有，但在純前端的靜態網站上要加 reCAPTCHA 得再接一組金鑰與驗證請求，先用上面三層擋；之後真的收到垃圾信再加。
