# 人才發展改為導向 104，移除站內職缺與教育訓練

客戶指定比照舊站 `career.php` 的作法：人才發展頁只放一段標語與一顆「人才招募」按鈕。

## 決定

**`/careers` 只保留標語與連往 104 企業頁（`https://www.104.com.tw/company/cq63bd4`）的按鈕**，站內的職缺與教育訓練列表、以及後台 `/admin/careers` 的維護功能全部移除。求職者本來就在 104 找工作，站內列表的曝光量比不上 104，而重複維護兩邊只會讓站內那份先過期；後台也因此少一個沒人維護的模組。

內容試算表的「人才發展」工作表**保留未刪**（資料還在，網站只是不再讀它），`apps-script/admin-api.gs` 的 careers 動作也**保留未改**——改了要重新部署才生效，留著幾個用不到的動作不會造成問題，動它反而會讓線上版本與 repo 不一致。
